# AI Energy Optimization Agent

A foundation for forecasting energy demand, detecting anomalies, and generating optimization recommendations.

## Project structure

- `backend/`: API and application services
- `frontend/`: User-facing application
- `ml/`: Forecasting, anomaly detection, and recommendation workflows
- `data/`: Raw and processed datasets
- `notebooks/`: Exploratory analysis
- `reports/`: Generated reports
- `docs/`: Project documentation
